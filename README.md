## Опис проєкту

Проєкт описує AI-агента **build-engineer** для GitHub Copilot. Агент автоматизує створення кросплатформного Rust-проєкту Hello World із юніт-тестом `BasicAddition`, скриптами `ci.bat` і `ci.sh` та GitHub Actions для Windows, Linux і macOS. Запуск `/init` має послідовно підготувати Git, проєкт, локальну збірку, CI та перевірити результат.

Структура агента передбачає **manifest**, **3 skills** і **6 команд**: п'ять окремих команд та команду-оркестратор `/init`. Їхні файли будуть додані на наступних кроках.

## Запуск агента

1. Відкрити проєкт у VS Code.
2. Відкрити Copilot Chat.
3. Перейти в режим **Agent**.
4. Вибрати агента **build-engineer**.
5. Оскільки у VS Code є вбудована команда `/init`, запустити наш оркестратор через прикріплення prompt-файлу:

   ```text
   #init.prompt.md Виконай цей prompt-файл повністю
   ```

   Або через **Ctrl+Shift+P → Chat: Run Prompt File → init**.

Інші команди агента запускаються як звичайні slash-команди: `/git-init`, `/create-project`, `/create-build`, `/create-actions`, `/check`.

## Запуск проєкту

Наведені нижче файли з'являться після виконання `/init`:

```text
ci.bat                 # Windows
./ci.sh                # Linux/macOS
cargo run --bin hello  # запуск програми
cargo test             # запуск тестів
```
